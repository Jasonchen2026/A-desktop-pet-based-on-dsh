# refs：挂外部只读目录的地方

想让她看工作区以外的资料，有两种办法，先试第一种。

**一、在权限文件里加路径（推荐）。** 打开 `neko-plugin/neko-guard/policy.json`，往 `readable` 列表里加一行，比如 `"D:\\论文\\参考资料"`。反斜杠要写两个，存盘立刻生效，不用重启。

**二、挂进这个文件夹。** 第一种被沙箱挡住时再用。在普通命令行里运行（不需要管理员权限）：

```
mklink /J "<仓库路径>\neko\refs\参考资料" "D:\论文\参考资料"
```

不想给她看了，删掉 `refs` 下面那个链接就行，删链接不会动原目录。

别挂整个用户目录或者几十 G 的大目录，她会一层层翻进去。
