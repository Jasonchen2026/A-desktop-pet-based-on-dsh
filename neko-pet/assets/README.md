# 形象图放这里

仓库里只带了占位图和托盘图标。把你自己的表情图放进这个文件夹，文件名对上 `neko-pet/config.json` 里 `expressions` 写的路径就行，默认是这八个：

`calm.png` `happy.png` `smug.png` `shy.png` `sleepy.png` `annoyed.png` `worried.png` `surprised.png`

所有图画布一样大、角色底边对齐、背景透明。尺寸填到 `config.json` 的 `canvas` 里。详细写法见仓库根目录的 README。

托盘图标是 `tray-awake.png`（醒着）和 `tray-sleep.png`（打盹），各有 16、24、32 像素三个尺寸，想换就按同样的文件名替换。
